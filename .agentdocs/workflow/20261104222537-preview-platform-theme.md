# 平台选择时即时预览主题并平滑过渡

## 背景与目标

- 关联会话：会话-20 起。
- 起始分支：`main`，与上一轮 GitHub 发布任务一致，工作区干净。
- 用户截图中已选 B站，但背景仍为抖音主题，确认按钮仍为红色。
- 目标：选择平台时，背景工作台、品牌标识、确认按钮、选中边框、单选标记和输入框焦点色立即联动，并平滑过渡到对应主题。

## 约束与决策

- 预览只改变呈现主题，确认前不改变当前游戏账号或写入存档。
- 取消或 Escape 关闭时恢复实际账号主题；确认后正常切换独立存档。
- 保留弹窗及平台卡片节点，避免重新生成 DOM（页面节点）打断颜色动画或重置键盘焦点。
- 使用 320 毫秒颜色过渡；背景渐变色阶使用注册的 CSS 颜色属性插值。
- 保留系统减少动态效果偏好，启用该偏好时不播放过渡。

## 代码变更

- `creator-studio/dist/app.js`
  - 新增统一主题应用逻辑，预览时使用候选平台，其他场景使用实际账号平台。
  - 背景侧栏与顶部同步显示候选平台标识及名称。
  - 平台选择仅更新卡片状态、昵称和按钮内容，不再重建整个弹窗。
  - 使用 `aria-pressed` 表达每个平台卡片的选中状态。
- `creator-studio/dist/style.css`
  - 将横幅及侧栏成长卡片的背景渐变抽为可插值的颜色变量。
  - 为主题相关背景、文字、边框、按钮、焦点、图表及图标添加平滑过渡。
- `.agentdocs/index.md`
  - 添加本次任务索引。

- 当前已完成本地桌面浏览器验证；减少动态效果偏好和本轮手机布局尚未单独复测。
