# UP主模拟器 · 创作由你

在抖音、哔哩哔哩、小红书三种主题工作台中经营模拟账号，通过作品发布、直播互动和数据复盘冲击人气榜。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

浏览器打开 http://localhost:4173。静态部署目录为 `creator-studio/dist/`，无需打包构建。

Sites 托管发布前执行 `npm run build`，使用生成的根目录 `dist/`。该步骤只合并单文件并复制静态资源，不安装或编译框架。

也可以运行 `npm run build`，然后双击 `creator-studio/dist/standalone.html` 直接试玩。单文件版内嵌全部图片、样式和脚本，无需联网；其存档与在线版本分别保存在对应浏览器来源下。

## 游戏玩法

- 初次进入选择平台与昵称，每个平台都有独立的浏览器本地存档。
- 起步账号包含 1,286 位粉丝、3 条历史作品、¥3,000 资金和 100 点能量。
- 发布作品时选择题材、制作投入和内容策略。平台偏好、热点、口碑和随机推荐共同影响曝光；高成本作品不保证高收益。
- 直播包含 5 轮互动，每轮有 3 个回复。选择会改变关注、取关、观众停留、礼物、互动意愿和口碑。
- 每日任务可领取资金奖励。直播任务需要完成全部 5 轮互动；任务奖励每日重置。
- 结束今日后恢复能量，结算作品长尾收益，更新热点与榜单。热度会适度衰减。
- 数据看板展示真实游戏状态、历史趋势、内容表现、完播率与账号口碑；作品详情解释推荐表现。
- 冲榜目标依次为 TOP 8、TOP 5、TOP 3 和第 1 名，保留历史最佳成绩。

## 验证

```sh
npm test
npm run check
```

测试使用 Node.js 内置测试工具，覆盖平台差异、资金与能量、运气、限流、直播分支、每日结算、任务奖励、排名、趋势图和存档校验。

## 数据与素材

- 这是独立模拟游戏，不连接真实平台账号，不上传玩家游戏存档。
- 榜单使用真实创作者姓名作为游戏挑战角色，热度、顺序和变动均为游戏设定，不代表真实排名或粉丝数。
- 姓名资料参考：[B站创作者公开内容](https://www.bilibili.com/video/BV16K4y1B7qh/)、[抖音创作者公开内容](https://www.douyin.com/hashtag/7461210570814195722)、[小红书公开创作者资料](https://toobigdata.com/red/h/bf3477dafc498776a575b7ff7864f9d9/)。平台资料与名单均不作为实时数据。
